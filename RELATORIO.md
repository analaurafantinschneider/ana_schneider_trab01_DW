# ana_schneider_trab01_DW
Construção do site

Utilizando como modelo de base um site já produzido durante o primeiro trimestre, separei os códigos css e html para que atingissem os critérios. O conteúdo so site, como textos e imagens, foi mantido, enquanto que a estrutura de múltiplas páginas foi modificada para que o mesmo se tornasse single page.
O código css agora se encontra renovado, contando com estruturas melhores e mais apelativas, apesar de se manterem simples.
O site trata-se de uma curta biografia da banda de Black Metal norueguês, Mayhem, através de poucas sessões abordando os pontos principais e de maior destaque na história da banda.

GitHub Pages

Apesar de sem conhecimento prévio sobre, através de busca pelo próprio site do GitHub e breves pesquisas, consegui acionar a função Pages para o repositório.
Como primeiro passo para acionar o pages, precisamos criar um repositório público, em seguida fazer os commits necessários e então abrir a página de configurações e a aba pages, onde selecionamos o arquivo correto.

Com o fim da atividade, descobri o modo de se utilizar a função, o que antes não sabia fazer e pude também explorar melhor as lições de css e html para melhorar um projeto iniciadp no começo do ano.
